# Security Policy

## Supported versions

Security fixes are provided for the latest stable release on `main`. Development snapshots and older
template-derived applications must update or backport fixes themselves.

## Reporting a vulnerability

Do not open a public issue. Email `security@neotamia.re` with:

- the affected component and version or commit;
- reproduction steps or a proof of concept;
- the impact and realistic attack conditions;
- any mitigation already identified;
- a safe way to contact you.

Do not include credentials, personal data or production secrets. The maintainers will acknowledge the
report, investigate it privately and coordinate remediation and disclosure. Please allow a reasonable
fix window before publishing details.

## Scope

Reports about this template's source, automation or published container images are in scope. A
vulnerability introduced only by a derived application's own dependencies or business code belongs to
that application's maintainers.
